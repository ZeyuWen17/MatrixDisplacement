# V1.1.1 Windows 开发与验收记录

日期：2026-11-06。此记录是本机执行证据，不代表其他电脑或全部交互通过。

## 本阶段修复

- Windows PowerShell 5.1 无法正确解析无 BOM 中文脚本：两个 `.ps1` 改为 UTF-8 BOM。
- 验收脚本 `python -c` 内嵌双引号被 PowerShell 5.1 转义破坏：移除无必要的输出表达式，保留 Qt 导入检查和退出码判断。
- 旧 GUI 回归测试硬编码 V1.0：标题、界面版本和测试统一读取包的 `__version__`，当前为 1.1.1。
- 所有测试自动隔离恢复目录，避免扫描或清理用户真实草稿。
- 构建使用 PyInstaller Qt 和 Matplotlib 导入钩子，取消收集所有子模块；显式保留 Qt 绘图后端。
- 首次打包误收集 PATH 中 Poppler 附带的 ICU DLL，导致 EXE 导入 QtCore 失败。构建时将 PATH 限定为项目虚拟环境和 Windows 系统目录，结束后恢复；不修改系统环境配置。
- 增加 `-SkipDependencyInstall`，支持已安装依赖时构建；EXE 离屏自检采用隐藏启动、120 秒超时和退出码检查。
