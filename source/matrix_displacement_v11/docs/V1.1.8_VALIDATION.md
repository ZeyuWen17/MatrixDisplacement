# V1.1.8 支座显示验收

日期：2026-11-11。

## 修改

七种非空 ux/uy/rz 组合使用不同的符号几何；滚轮沿允许平动方向滚动，转角约束使用带叉方框辅助标记。仅连接 Beam2D 的 uy/rz 约束显示梁固定端。非零给定位移以橙色及数值显示；未更改求解算法或模型约束。

建模画布和 Matplotlib 结果图共用 `supports.py` 定义。标注包含自由度、m/rad 单位，鼠标悬停可查看详情；导出图片保留支座符号与非零给定位移数值。

## 验收

- 完整回归 312 passed、1 skipped；新增六项验证覆盖七种符号区分、滚轮方向、梁与刚架区分、非零位移及真实 Qt 画布和 PNG 输出。
- [测试日志](../reports/validation/pytest-v118.txt)、[构建日志](../reports/validation/build-v118.txt)。
- 源码与打包 EXE 自检通过；构建时再次执行完整回归及九项 GUI 导出专项。[构建校验](assets/BUILD_VALIDATION_v118.txt)。
- [支座图例](assets/support-symbols-v118.png)由实际 Qt 画布生成并视觉核对；图例脚本为 `scripts/render_support_legend.py`。离屏 Qt 未枚举系统字体时，图例脚本显式加载系统微软雅黑。
- 仅支持整体 X/Y 方向约束；转角辅助方框属于程序图例，不宣称是所有教材统一采用的支座符号。
- 此轮未进行多显示器或另一台无 Python 电脑实测。
