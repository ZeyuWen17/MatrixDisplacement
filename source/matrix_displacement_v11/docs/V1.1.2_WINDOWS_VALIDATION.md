## 明确限制

保存保护是保存前的内容检查，不是跨进程文件锁。极短的“检查后、写入前”并发变化仍可能覆盖，不提供自动合并。外部文件仅格式变化也会提示。

真实窗口验收覆盖上述操作，不等于全部鼠标交互通过。保存冲突分支目前为自动化验证，尚未完成两个真实窗口并发编辑的完整手动流程。高 DPI、多显示器、完整崩溃恢复流程、另一台无 Python 电脑及 GitHub Actions 仍待验证。
