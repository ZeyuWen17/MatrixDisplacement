# V0.7 Windows Qt 桌面测试清单

> 在项目根目录安装 `requirements-gui.txt` 并启动 `python -m matrix_displacement.gui`。该清单用于人工验证图形界面，并不宣称已经在当前构建环境完成。

- [ ] 首次启动看到 4 m 悬臂梁模型，选择“教学模式”，点击计算；出现数值结果、轴力、剪力、弯矩、变形五个结果页签。
- [ ] 在“教学算例”菜单切换到“两跨连续梁”，计算得到中间支座竖向反力约 **5000 N**，两端支座竖向反力各 **1500 N**。
- [ ] 在“三角形平面桁架”算例计算得到节点 1、节点 2 竖向支座反力各 **1500 N**；无奇异机构报错。
- [ ] 新建空白模型 → 选“绘制节点” → 鼠标点击三处产生三个节点，网格按 0.5 m 吸附。
- [ ] 选 Frame2D 后，依次点击两个节点创建杆件；双击杆件修改 E、A、I，并保存、重新打开 JSON 检查值。
- [ ] 支座工具可勾选 ux、uy、rz 并输入零或非零给定位移；修改支座后旧计算结果自动清除。
- [ ] 节点荷载工具可输入 Fx、Fy、Mz；再次编辑应替换原值而不是累加。
- [ ] 杆件荷载工具能选择均布、杆内集中力、线性分布荷载，以及局部/整体坐标系。
- [ ] 对 Truss2D 尝试杆件荷载，程序应显示友好拒绝信息而不是退出。
- [ ] 杆件施加集中力后，弯矩图保持连续、剪力图有突变（用数值表独立核对）。
- [ ] 选择工具双击节点后修改坐标；修改使某杆件变为零长应给出错误提示且不破坏模型。
- [ ] 选择工具选择杆件，点击“清空选中杆件的所有荷载”后杆件荷载项归零。
- [ ] 删除节点时应弹出确认，确认后删除关联杆件和杆件荷载。
- [ ] 导出教学 `.md` 报告、CSV 和 PNG；检查文件可打开，PNG 与当前结果页相符。
- [ ] 切换“快速模式”重新计算后尝试导出教学报告，应提示切回教学模式；CSV/PNG 仍可导出。
- [ ] 打开包含旧 `schema_version=1` 或现行 `schema_version=2` 的 JSON 模型，检查节点坐标和荷载。
- [ ] 模型有未保存更改时关闭窗口，弹出保存/放弃/取消确认。
- [ ] 运行 `python -m pytest -q`，Qt 测试应不再被跳过，查看是否全部通过。

**范围限制：** 本清单为交互性和数值基础验收，不代替复杂结构或工程案例验证。请记录 Python 版本、PySide6 版本、Windows 版本、缩放/DPI 以及失败截图。
