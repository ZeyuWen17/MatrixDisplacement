## 已验证的计算与限制

自动测试包含悬臂梁、简支梁、连续梁、平面桁架、斜杆坐标转换、混合单元、杆端释放、支座沉降，以及节点/均布/集中/线性荷载、组合叠加和截面响应等。通过已有测试不代表任意输入模型都正确。

适用二维小变形线弹性静力分析；不支持空间、动力、非线性、屈曲或规范设计。桁架只支持节点荷载，Beam2D 要求水平且按左至右连接。组合共用支座，给定位移施加一次，不提供自动规范组合或包络。内力标注极值为采样结果。完整文字布局及单张 PNG 写入期间取消需等待步骤结束。荷载箭头仅作示意，实际大小以数值为准。

当前离屏验收不等于多显示器、所有显示缩放或另一台无 Python 电脑的人工测试；这些情况不宣称全部通过。
