# V1.1.7 优化与验收记录

日期：2026-11-11。

## 行为变化

- GUI 计算入口使用独立模型快照和后台线程；主线程继续处理事件。计算期间禁用模型编辑、菜单和工具栏，显示不定进度条及取消入口。
- 取消会丢弃结果，等待底层数值运算安全结束。运行中不销毁窗口或线程；失败后恢复界面可操作状态。结果接收时再次核对模型快照，拒绝过期结果。
- 数值结果先显示，四张结果图首次查看或导出时才生成。没有变化的图页直接复用；标注模式变化后按需重绘。全部导出仍确保生成四张图。
- 标注布局缓存以像素坐标、文字边界、障碍物和 DPI 为键，窗口尺寸或导出尺寸变化会失效。
- 对非正刚度对角项报告具体节点/自由度；对近零特征模态报告最多八个候选自由度，注明不是唯一故障原因。错误发生时选中相关节点并显示全模型。
