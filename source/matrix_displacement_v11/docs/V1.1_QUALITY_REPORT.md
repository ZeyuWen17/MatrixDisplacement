# V1.1 验证边界记录

- 继承 V1.0 的 243 项非 Qt 回归测试，并增加新的无 Qt 恢复与启动验证。
- `tests/test_recovery_v11.py` 验证了原子快照、文件损坏、模式版本、校验码、非法路径、恢复后仍未保存等情况。
- `tests/test_gui_startup_v11.py` 验证错误日志写入和无 PySide6 时的错误返回。
- `tests/test_gui_smoke_v11.py` 为**依赖 PySide6 的可选 Qt 冒烟测试**，包括自动保存、手动保存与恢复模型分支。此环境缺 PySide6，测试模块被跳过。
- Windows 构建脚本和 GitHub Actions workflow 仅已编写及审阅；当前环境未运行 Windows EXE 或 Qt 真正窗口。
- 目前测试统计：**259 passed, 5 skipped**（Qt V0.7～V1.1 这 5 个模块被跳过），不是 264 passed。
- V1.1 使用用户本地恢复目录，采用原子写入及 SHA-256 内容校验；校验用于防损坏而非防恶意篡改。
- 不包括实际断电掉电测试、不同 Windows/DPI 机器兼容性、完整数值可靠性工程认证。
