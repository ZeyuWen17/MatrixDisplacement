# 矩阵位移法结构分析与可视化教学系统

**版本：V0.8.0（2026-11-06）**  
**语言 / 平台：** Python 3、Windows 桌面（PySide6），数值内核跨平台  
**核心用途：** 结构力学课程学习、矩阵位移法步骤验证与二维杆系结构分析  
**单位：** 国际单位制 SI：m、N、Pa、m²、m⁴、N·m、rad。

> **使用边界：** 软件为线弹性、小变形、静力分析的**教学原型**，不是工程设计认证软件。请独立验证重要计算结果。V0.8 的 GUI 已完成源代码与测试入口，但本构建环境未安装 PySide6，所以**桌面窗口、鼠标拖拽及系统对话框没有经过实际 Qt 运行验证**；已验证非 Qt 的数值、数据编辑及查询模块。

## 1. 用户需求与项目目标

项目将逐步提供：

1. **结构类型：** 平面刚架、平面桁架、连续梁；保留未来扩展到空间桁架 / 空间刚架的模块接口。
2. **技术路线：** Python，先搭建数学内核，再开发 PySide6 图形界面；计算层和界面层独立。
3. **矩阵位移法求解：** 单元局部刚度、坐标转换、整体刚度矩阵组装、边界条件、节点位移、支座反力和杆端内力。
4. **后处理：** 任意杆截面轴力 N(x)、剪力 V(x)、弯矩 M(x)、变形场，以及内力图、变形图。
5. **教学模式和快速模式并存：** 两者使用同一线性静力求解算法；教学模式保存单元矩阵、自由度和组装过程，快速模式不保存繁重的步骤记录。
6. **操作：** 支持从 JSON 输入，也支持桌面鼠标创建结构、编辑参数、求解、查看并导出结果。

### V0.8 本轮新增详情

- **历史记录 `EditHistory`：** 新增独立的 `history.py`，以模型快照记录增、删、改、支座、杆件荷载、截面参数及默认参数修改；`Ctrl+Z` 撤销、`Ctrl+Y` / `Ctrl+Shift+Z` 重做。最多保留 100 个模型操作。新编辑会清除重做分支；打开、新建或切换算例将清空历史。保存 JSON 后能识别通过撤销恢复到已保存状态。历史本身不保存到 JSON。
- **节点拖拽：** 选择工具下按住已有节点拖动，移动过程中进行几何有效性检查；松开时提交为**一个历史操作**。失败自动恢复原状态。`Beam2D` 必须保持水平且 i 端在左侧，不能拖成斜梁。
- **网格吸附：** 默认吸附到 0.5 m 网格；可取消勾选以在画布上使用非网格坐标，也可用精确坐标弹窗直接输入。
- **荷载标注：** 节点力 / 力矩显示有符号数值；杆件荷载显示局部/整体坐标系及各分量。密集模型中的文本仍可能重叠。
- **杆件属性表：** 列出杆件 ID、单元类型、端点、长度、E、A、I 和荷载数量；点击行可定位并选中杆件。
- **杆件荷载表：** 逐条列出荷载，允许单独修改荷载类型、坐标系和数值，或单独删除；其他荷载不受影响，且更改可以撤销。
- **截面交互查询：** 求解后在“杆件截面查询”页签选择单元和距 i 端的位置 x，查看 N/V/M、整体坐标位移与转角；集中力位置可查询左 / 右极限。也可以查看节点各自由度位移及反力。表中极值属于**采样范围**，不是所有情况下严格的数学极值。

## 3. 运行环境与 Windows 安装

解压 ZIP 后，从 `matrix_displacement_v08/` 项目根目录打开 PowerShell。

### 3.1 GUI 安装

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-gui.txt
```

上一步需要能够连接 Python 包索引来安装 **PySide6**、NumPy、Matplotlib、pytest。

### 3.2 运行图形界面

```powershell
.\.venv\Scripts\python.exe -m matrix_displacement.gui
```

也可以双击 `install_gui_windows.bat` 安装到默认 Python，双击 `run_gui_windows.bat` 启动。使用虚拟环境时建议优先用上面的显式命令。

### 3.3 运行全部测试

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

**当前 Linux 构建环境实际结果：** `190 passed, 2 skipped`。跳过的两个模块是 `test_gui_smoke_v07.py` 和 `test_gui_smoke_v08.py`，原因是构建环境没有 PySide6，并非 GUI 测试已经通过。在安装 PySide6 的 Windows 上应重新运行。

### 3.4 不依赖 Qt 的 V0.8 示例

```powershell
python -m pip install -r requirements.txt
python -m examples.inspection_workflow_v08
```

会生成 `outputs/examples/artifacts_v08/structure_v08.json` 和 `outputs/examples/artifacts_v08/inspection_report_v08.txt`，展示模型操作历史、节点位移与杆件受荷截面查询。

## 4. 图形界面使用说明

### 4.1 建模

1. 启动后预加载悬臂梁算例，可直接点击“**计算并显示结果**”。新建空白模型使用 `Ctrl+N`。
2. 选择“**绘制节点**”，点击画布创建节点；默认按 0.5 m 吸附，可取消勾选。也可以“精确输入节点坐标”。
3. 从“新建杆件类型”中选择 `Frame2D` / `Truss2D` / `Beam2D`，再用“连接杆件”依次点击两个节点。
4. 用“设置支座”工具给自由度施加零或非零已知位移；用“节点荷载”工具添加 / 替换节点力和力矩；用“添加杆件荷载”工具设置杆内荷载。
5. 使用“**选择**”工具点击节点或杆件，双击弹窗编辑；也可以从杆件属性表选择杆件。**按住节点并拖动**可以移动节点，松开后保存一次操作。
6. 用左侧“**杆件荷载表**”选中单条荷载，点击“修改所选荷载”或“删除所选荷载”。“清空选中杆件的所有荷载”仍可批量删除。
7. 编辑菜单“撤销 / 重做”或快捷键 `Ctrl+Z` / `Ctrl+Y`。撤销和重做会清空旧的求解结果，需要重新计算。

### 4.2 查询与导出

1. 选择“教学模式”或“快速模式”，点击“计算并显示结果”。
2. 在“数值结果”查看自由度与杆端力；“轴力 N / 剪力 V / 弯矩 M / 变形图”页签查看图片。
3. 切换到“**杆件截面查询**”，选择杆件和位置 `x`，读取截面内力、整体位移和角度；如果恰好位于杆内集中力点，可切换“左侧极限 / 右侧极限”，剪力可出现跳跃而弯矩连续。
4. 教学模式可以导出 `.md` 教学计算报告，任何模式都可以导出 CSV 和当前 PNG 图；结构模型使用 JSON 保存 / 打开。

### 4.3 单位、正负号和约束

- 纵坐标向上为正，单位：m / N / N·m；弹性模量 Pa，截面惯性矩 m⁴。
- 全局 `Fx` 向右为正、`Fy` 向上为正，节点逆时针力矩为正；杆件局部坐标以 i→j 为局部 x 正向，局部 y 为其逆时针 90°。
- `Beam2D` 仅用于由左向右的水平连续梁，节点有 `uy, rz` 两个自由度；需要斜杆 / 轴向变形时使用 `Frame2D`。
- `Truss2D` 为纯轴向受力单元，只接受节点力；对桁架杆件的直接分布荷载不可用。
- 杆端释放表示 `Frame2D` 单元转角释放；不等于释放节点所有单元的转角。
- 关键数学符号及刚度推导参见 `docs/README_V0.6.md` 和过往 README。

## 6. 验证范围与未解决的限制

**已在构建环境实际验证：** Python 语法编译；原有刚架、连续梁、桁架及杆件荷载算例；V0.8 的事务回滚、快照还原、撤销/重做、单项荷载编辑、集中力断面左右极限、节点位移与支座反力查询；无 Qt 的示例 JSON 写入/重读。完整 ZIP 会重新解压并复测。

**尚未完成 Qt 实机验证：** Windows 实际窗口启动、节点拖拽、属性表的选中与弹窗、网格吸附操作、荷载文本布局、高 DPI 显示、快捷键、页面交互，以及安装依赖的 Windows 兼容性。已提供可选离屏 Qt 冒烟测试与人工检查清单，不应将其计入本环境“通过”的测试。

**数值方法局限：** 二维线弹性小变形静力；不支持空间结构、动力分析、材料与几何非线性、设计规范验算；稀疏求解器与大规模性能优化尚未实现；数值机构检查不保证发现所有病态结构；多个荷载工况与组合尚未完成；采样内力极值应通过解析方法校核。

**界面局限：** 暂未提供独立 `.exe`、模型多选、文字自动避让、比例尺和视图平移工具、弹性支座及半刚性连接。含大量荷载和节点时画布文本可能重叠，宜使用属性表精确查看。
