# V0.8 Windows GUI 人工验收清单

本环境 PySide6 未安装，以下事项必须在安装 PySide6 的 Windows 电脑上逐项验证。测试之前先使用 `python -m pytest -q`，确认两个 Qt 冒烟测试模块不再跳过。

- [ ] PowerShell 创建 `.venv`、安装 `requirements-gui.txt`、启动桌面窗口，无 Qt 插件错误。
- [ ] 默认悬臂梁可求解；结果页有数值、杆件截面查询、N、V、M、变形图共 6 个页签。
- [ ] 新建模型时节点可鼠标吸附 0.5 m 网格；取消网格吸附后节点坐标不强制四舍五入。
- [ ] 选择模式下拖动一个 `Frame2D` 节点，单次 Ctrl+Z 能完全还原位置，Ctrl+Y 能重做。
- [ ] 将连续梁节点拖离水平线：程序禁止修改，原模型不损坏。
- [ ] 在已保存模型上移动节点后显示 `*`；撤销到已保存状态后 `*` 消失。
- [ ] 节点的 Fx/Fy/Mz 显示有符号数值；均布、集中、线性杆件荷载标注数值及局部/整体坐标系。
- [ ] 杆件属性表列出 E/A/I/杆长；选中表格行后能定位同一杆件并编辑属性。
- [ ] 杆件荷载表可单项修改荷载类型、坐标系与数值；其他荷载保持不变；修改可撤销。
- [ ] 杆件荷载表可删除单项荷载，恢复后值及顺序正确。
- [ ] 结果“杆件截面查询”设置 x=1.7 m，在集中力点切换左右极限，剪力差应为 -700 N，弯矩连续。
- [ ] 点击杆件属性表后，查询页的杆件选择和选中高亮保持一致。
- [ ] 点击节点，查询页显示对应自由度位移与反力；重新选择另一杆件后可继续截面查询。
- [ ] 编辑模型后旧计算结果清空；导出操作会要求先重新计算。
- [ ] 使用 JSON 保存 / 关闭 / 读取后，节点、单元、支座、荷载及计算结果一致；历史从空重新开始。
- [ ] 放大缩小、滚动条、中文字体和系统对话框在 100% / 150% Windows DPI 下显示正常。

若有错误，请保留错误窗口截图、重现步骤、Python 与 PySide6 版本以及终端完整异常回溯。
