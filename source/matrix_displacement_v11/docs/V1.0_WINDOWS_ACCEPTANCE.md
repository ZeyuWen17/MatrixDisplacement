## 已知限制 / 未完成事项

1. 当前构建/测试环境没有 PySide6、不是 Windows；**没有运行真实 Qt GUI，也未生成已验证的 `.exe`**。
2. 标签避让属于有限候选位置的贪心算法；极密模型、交叉线段及画布边缘仍可能重叠，**不是完美的全局自动排版**。
3. 多选以节点和杆件为单位；尚不支持框选杆件荷载子项、拖拽对齐参考线、复杂几何 CAD 约束。
4. 目前仅实现二维小变形线弹性静力计算，非线性、三维结构、动力学和工程规范校核尚未实现。
5. 极端刚度比、病态矩阵和复杂机构仍需人工校核，本项目不属于经过工程认证的软件。
