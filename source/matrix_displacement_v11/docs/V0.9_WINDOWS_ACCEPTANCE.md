# V0.9 Windows GUI / EXE 验收清单

**当前状态：尚未在 Windows 实机完成。** 本文档不是通过报告，是提供给 Windows 使用者的测试步骤。执行时逐项记录日期、Windows 版本、Python/PySide6 版本、失败截图或日志。

## 1. Python GUI 验证

在项目根目录运行：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-gui.txt
powershell -ExecutionPolicy Bypass -File .\scripts\windows_acceptance.ps1
.\.venv\Scripts\python.exe -m matrix_displacement.gui
```

- [ ] GUI 正常启动，无 Qt `platform plugin` 或 Matplotlib 后端错误。
- [ ] 默认悬臂梁显示节点、杆件、荷载标注及 **L/θ** 尺寸，菜单开关可显示/隐藏尺寸。
- [ ] 鼠标滚轮、`视图→放大/缩小`、`Ctrl+0` 适应窗口均有效。
- [ ] 任意工具下按住鼠标**中键拖动**能平移画布；“平移画布”工具下按左键拖动能平移且不会创建节点。
- [ ] 使用“选择”工具拖动节点，撤销和重做分别还原及重现坐标；网格吸附开关有效。
- [ ] 新建节点、连接 Frame2D / Truss2D / Beam2D，设置支座、荷载、编辑杆件及删除，状态与数据表一致。
- [ ] 运行计算后选择 **轴力 N、剪力 V、弯矩 M** 图，点击计算曲线上的位置，自动转到“杆件截面查询”页签，位置 x 与所点位置相符。
- [ ] 对悬臂梁在集中力位置 x=1.7m 的左右极限切换，剪力跳跃量约为 -700 N，弯矩连续。
- [ ] 不合法的输入或不稳定结构会显示明确的失败提示，主窗口不会意外退出。
- [ ] 保存 JSON 后关闭再打开，模型、支座、荷载均还原。
- [ ] 导出 PNG / CSV / 教学 Markdown 报告均成功，内容可打开。
- [ ] 高 DPI (125% / 150%)、不同分辨率、中文字符、长杆件标签和多根密集杆件的显示效果可接受。

## 2. Windows EXE 构建和验收

在 Windows 上运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build_exe_windows.ps1
.\outputs\dist\MatrixDisplacement\MatrixDisplacement.exe
```

- [ ] PyInstaller 成功生成 `outputs/dist/MatrixDisplacement/MatrixDisplacement.exe`。
- [ ] 关闭 Python 开发环境后仍能直接启动 EXE，窗口内没有缺图标、缺 Qt 插件、缺 Matplotlib 后端等问题。
- [ ] 对 EXE 重复至少一个完整建模 → 求解 → 查询 → 保存/导出流程。
- [ ] 将 **整个 `outputs/dist/MatrixDisplacement/` 文件夹**复制到另一台未安装 Python 的 Windows 电脑，应用可启动并完成基础流程。
- [ ] 检查杀毒软件误报和 SmartScreen 提示：本项目未包含代码签名，用户需要自行判断可信来源，不应要求关闭系统防护。
