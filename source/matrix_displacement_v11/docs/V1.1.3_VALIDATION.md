# V1.1.3 保存完成状态修复

日期：2026-11-07。

修复：原逻辑在文件已写入后，如读取校验信息或清理恢复草稿失败，会返回保存失败，甚至未更新另存为路径。现在把实际写入与后续处理分开：写入成功立即更新路径、历史保存基准、标题及未保存标志；后续失败显示持续状态栏提示，不伪装成写入失败。

- 草稿清理失败：保留草稿并提示它可能不是最新版本，后续再次保存可重试清理。
- 校验读取失败：保存仍成功；将源文件基准标记为未知，下次覆盖已有文件时要求确认。
- 实际写入失败：仍返回失败，保留未保存状态与恢复草稿。

验证：完整回归 280 passed、1 skipped（非 Windows XDG 路径测试）；新增 3 个故障注入测试，分别覆盖草稿清理失败、保存后校验读取失败和实际写入失败。日志见 reports/validation/build-v113.txt。

范围：本轮验证为自动化与打包自检，不新增真实鼠标验收结论。关闭、新建或切换模型时的草稿清理异常仍需后续单独完善。保存冲突检测仍不是文件锁，不提供自动合并。跨电脑、高 DPI、多显示器及完整恢复交互仍待验证。

EXE 构建和打包后离屏自检通过，SHA-256 与构建报告一致。见 reports/validation/BUILD_VALIDATION_v113.txt。
