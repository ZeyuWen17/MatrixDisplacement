# 本地模型检查与支座预设

日期：2026-11-11。本记录保留此前仅本地开发阶段的验证过程；这些功能已纳入 V1.1.9，当前状态见 [V1.1.9 验收记录](V1.1.9_VALIDATION.md)。

## 功能

计算入口在创建后台线程前运行只读检查；也可从“分析与导出”菜单主动检查。确定错误阻止计算，建议可在核对后继续。点击条目选中并缩放到相关对象；诊断视图使用显示副本，避免异常几何再次触发计算，不自动修改模型。检查视图省略荷载和尺寸。

错误覆盖空模型、零长度/方向不适用的杆件、缺失节点/材料/截面引用、无效节点荷载与给定位移、无效杆件荷载。建议覆盖孤立节点、完全相同坐标的不同节点、独立结构组及没有约束的结构组。不会自动合并重合节点；不检查任意容差内的近似重合，不替代求解器稳定性判断。

支座预设按有效自由度适配，切换预设保留位移值，支持继续自定义。预览使用与画布相同的符号定义，输入非有限数值时给出提示；确定才应用，取消保留原模型。

## 验证

新增测试覆盖只读检查、三个教学算例、独立结构合法性、无效引用与几何、无效荷载、三类单元自由度预设、输入保留/取消、实时预览、错误阻止启动、建议取消及确认继续、问题定位。

最终完整回归 **330 passed、1 skipped，退出码 0**，见[本地回归日志](../reports/validation/pytest-local-preflight-final.txt)。支座窗口通过实际 Qt 离屏渲染核对，预览保存在本地 `outputs/acceptance/local-preflight/support-dialog.png`。本轮不宣称真实鼠标操作验收。

首轮全量测试所有断言通过后发生一次 Qt 退出异常，复跑正常；随后为新增测试显式销毁窗口，再运行最终回归。日志保留，不将首次异常记为正常退出。
